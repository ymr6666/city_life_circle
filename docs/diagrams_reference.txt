图 2：功能模块图（必画，对应"功能设计"）
========================================================

布局：自上而下树状结构。

根节点：城市时域生活圈分析系统（深蓝大框）

七个一级子节点（同层横排，各自下面挂二级叶子）：
1) 生活圈分析
    - 多模式等时圈（步行/骑行/驾车/地铁/公交）
    - 圈内设施统计 · 覆盖人口
    - 多分析点同图对比
    - 覆盖率-时间曲线
2) 宜居评分
    - 五维评分（医疗/教育/购物/休闲/交通）
    - 用户权重 + 家庭结构预设
    - 评分卡（事实-权重-参考分三层透明）
3) 反算选址
    - 设施覆盖范围
    - 多设施交集 = 最优居住选址
4) 分级色彩
    - 四边形/六边形网格
    - 综合宜居评分 / 单类设施密度
5) 人口分布
    - 100m 人口密度瓦片底图
    - 区域/多边形人口统计 · 小区分布
6) 全城分析
    - 盲区识别 / 盲区聚类 / 错配分析 / 均衡分析
7) 规划分析
    - 选址模拟 / 关闭影响 / 搬迁影响

【配色】一级节点按功能给不同色（生活圈=蓝、评分=绿、选址=橙、全城=红、规划=紫 等）
【连线】根→7 个一级节点；一级→各自叶子

图 5：算法流程图（高价值，二选一，对应"关键技术"）
========================================================

方案 A：等时圈生成流程（横向流程图，六个框 + 箭头）
  输入：起点坐标 + 出行方式 + 时间预算
   → 坐标吸附到最近路网节点（自适应半径 150-800m）
   → 构建多模式统一时间成本图（道路+地铁+公交）
   → 单次 pgr_drivingDistance（Dijkstra）求解
   → 得可达节点/地铁站/公交站 + POI 反查
   → 可达道路边做街道缓冲合并
   → 输出等时圈多边形 + 设施统计/覆盖人口

方案 B：反算选址流程
  输入：设施坐标集合（如公司、学校）
   → 逐设施多源反向 Dijkstra（有向模式自动反转单行道）
   → 得各设施"能到达它的起点"覆盖范围
   → 多设施覆盖求交集
   → 输出最优居住选址区 + 覆盖人口

【在每个框下加小字参数】：速度 步行5/骑行15/驾车30 km/h 等

  浏览器 → 后端(waitress :5000，托管前端构建产物+API) → 数据库(本地 PostgreSQL+PostGIS+pgRouting)
