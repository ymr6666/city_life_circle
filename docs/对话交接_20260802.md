## 一、项目定位

回答"住在这里，我的生活怎么样"。个人视角生活圈分析：正算（地址→等时圈→设施统计→评分）+ 反算（设施→覆盖范围→选址）。核心差异化：多模式交通耦合 + 三层透明评分。

### 2.5 反算 `/api/reverse-isochrone` ✅

- `backend/engine/reverse.py`：设施坐标 → "能到达它的起点"覆盖范围；多设施交集 = 最优选址。
- **单行道处理**：数据含 29,099 条 oneway 边。步行类模式（无向图）正反一致；驾车/骑行（有向图）"能到达 F 的起点 ≠ 从 F 能到达的地方"，必须**反转边（swap source/target）**再 Dijkstra。已实现 `_edge_sql(swap)` / `_build_combined_edge_sql(swap)`，有向模式自动反转。实测 drive 反算 5,582 vs 正算 5,551（差异即单行道影响）。
- 多设施交集：逐设施反向多源 Dijkstra 后求节点集交集。
- 返回：每设施覆盖起点数 + 凸包 polygon；≥2 设施时返回交集。
