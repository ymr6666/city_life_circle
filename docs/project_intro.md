# 城市时域生活圈分析系统 —— 作品介绍与系统概述

> 版本：V1.0（2026-08）
> 一句话：输入一个地址，选择出行方式与时间，系统在真实路网上算出"你能走到哪、那里生活配套好不好"，并给出全城视角的设施布局诊断与规划建议。

---

## 一、作品简介

**城市时域生活圈分析系统**是一个面向**居民个人视角**的 WEBGIS 生活圈分析与诊断平台。

传统"生活圈"规划通常以行政区/网格为统计单元、输出宏观统计图表；本系统反其道而行之——
以**用户自己的地址为起点**，基于真实的道路网络、地铁与公交线路做**多模式最短路径计算**，
精确回答三个问题：

1. **"住在这里，T 分钟能到达哪些地方？"** —— 生成真实路网形状的等时圈（正算）；
2. **"我需要的设施在生活圈里够不够、好不好？"** —— 圈内设施统计 + 五维宜居评分；
3. **"如果某个设施关闭/搬迁/新建，对多少人有什么影响？"** —— 全城服务覆盖、盲区、供需错配与规划模拟（反算/规划）。

数据与算法全部自研构建，不依赖商业网络分析工具，现场可交互演示。

## 二、功能模块

| 模块 | 功能 | 亮点 |
|---|---|---|
| 生活圈分析 | 地址搜索 → 多模式等时圈（步行/骑行/驾车/地铁/公交）→ 圈内设施统计 | 最多 6 种方式同图对比、多点对比表、覆盖率-时间衰减曲线 |
| 宜居评分 | 医疗/教育/购物/休闲/交通五维评分 | 三层透明（事实→用户权重→参考分）、家庭结构预设（有老人/小孩自动调权） |
| 反算选址 | 以设施为源求"能到达它的起点"覆盖范围 | 多设施交集 = 最优居住选址（边域多边形，非凸包） |
| 分级色彩 | 六边形/四边形网格综合评分与单类设施密度 | 用户可自定义分级区间与图例，红→绿区分度高 |
| 人口分布 | 100m 人口栅格瓦片底图、区域/多边形人口统计、小区人口分布 | 预渲染瓦片任意缩放、手绘多边形统计 |
| 全城分析 | 服务盲区识别、盲区聚类、人口-设施错配、全城供需均衡 | 等级过滤（三甲/专科/基层），一次 Dijkstra 多阈值切片 |
| 规划分析 | 选址模拟、关闭影响、搬迁影响 | 填补盲区人口排序、独占覆盖/退级/净变化建模、多方案对比图 |

## 六、核心算法与创新点

### 1. 多模式耦合可达性（正算）
将道路边、地铁边、公交边、换乘边**统一为一张带时间成本的图**（节点 ID 按 路网/地铁 10万+/公交 20万+ 偏移），
单次 `pgr_drivingDistance` 求出"步行+地铁+公交"的联合可达域，而不是分段拼接。
道路侧支持步行 5km/h、骑行 15km/h、驾车 30km/h，并**尊重单行道与桥隧限制**。

### 2. 真实路网形状的等时圈
不用凸包/圆，而是把"预算内可遍历的道路边"按街道宽度 buffer 后合并，等时圈严格贴合道路走廊；
公交/地铁形成的**不连续可达孤岛**由 DBSCAN 逐簇凹包保留，形状真实可解释。

### 3. 反算与最优选址（反算）
"设施 → 能到达它的起点"即服务覆盖范围；多设施覆盖范围**交集**即为同时可达全部设施的**最优居住选址**。
有向模式（驾车/骑行）自动反转单行道边，保证"能到达设施"语义正确。

### 4. 一次 Dijkstra、多阈值切片
全城覆盖/盲区/均衡分析只需跑**一次**多源反向 Dijkstra，得到全成本剖面后按 5/10/15/30 分钟任意切片，
避免重复计算；设施源超过 200 个时自动用**虚拟超级节点**合并，复杂度与设施数解耦。

### 5. 服务盲区与独占覆盖（规划）
- 盲区 = 阈值时间内到不了任何该类设施的人口；
- **独占覆盖** = 某设施能到达、但同类其他设施到不了的人口 → 关闭影响的受影响人口；
- 关闭/搬迁影响进一步区分 **退级**（更长时限可到替代设施）与**完全失去**；
- 选址模拟按"填补盲区人口"排序，并分散到不同盲区簇避免扎堆。

### 6. 三层透明宜居评分
层1 事实数据（圈内加权设施数、最近设施距离、周边站点）→ 层2 用户权重 + 家庭结构预设 →
层3 参考分（0-100 + 优/良/中/差等级）。评分固定以"步行 15 分钟生活圈"为参照，保证不同出行方式可横向比较。

## 七、典型使用流程

1. 打开系统 → 搜索或点击地图定位一个地址；
2. 勾选出行方式（如步行+地铁）、设置时间（如 30 分钟）→「生成生活圈」；
3. 查看等时圈内的设施统计、覆盖人口与**宜居评分卡**；
4. 切到「反算选址」，把多个心仪地点设为设施，求同时覆盖它们的最优居住区；
5. 切到「全城分析」，查看某类设施的服务盲区、盲区聚类、供需错配与全城均衡；
6. 切到「规划分析」，模拟新建/关闭/搬迁某设施对覆盖人口的影响。

---

## 八、应用价值

- **个人购房/租房决策**：用真实路网而非直线距离评估"住这里生活方不方便"；
- **规划评估**：识别服务盲区、设施供需错配，量化关闭/搬迁/新建的影响人口；
- **教育/答辩演示**：算法全自研、现场可交互，区别于"工具使用者"式的商业软件演示。

## 九、部署形态

本系统支持两种交付形态（详见 `docs/deployment.md`）：

1. **本地运行**：打包源码 + 数据库备份 + 一键安装脚本，评委在自带电脑即可运行（Windows / Linux）；
2. **云服务器**：提供 Docker Compose 与手动部署两种方案，支持在线访问与 HTTPS。

> 所有坐标均为 WGS84（高德 POI 已由 GCJ-02 转换并保留备份表可回滚）。
