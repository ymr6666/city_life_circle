城市时域生活圈分析系统 —— 安装及配置文件说明

本文说明系统的安装脚本与配置文件：各自位置、作用、可配置项与修改方法。
适合作为提交材料或部署手册的配套说明。详细部署步骤见部署说明文档。

========================================================
一、安装文件说明
========================================================

系统提供"一键脚本 + 手动命令"两套安装方式，均不依赖 Docker。

1.1 一键安装脚本（deploy/scripts/ 目录）

install_windows.bat —— Windows 一键初始化
  功能：创建数据库 city_life_circle 并恢复备份、复制人口瓦片、创建 Python
  虚拟环境并安装依赖。
  运行：双击，或命令行执行 install_windows.bat。首次会提示输入 postgres
  数据库密码。

start_windows.bat —— Windows 一键启动
  功能：激活虚拟环境并启动后端服务（waitress），浏览器访问
  http://localhost:5000 进入系统。

install_linux.sh —— Linux/macOS 一键初始化（与 Windows 版功能一致）
start_linux.sh —— Linux/macOS 一键启动

deploy_manual_linux.sh —— Linux 全自动部署（服务器推荐）
  功能：自动完成 apt 安装 PostgreSQL/PostGIS/pgRouting/Python、建库恢复、
  低配调优、复制人口瓦片、安装依赖、注册 systemd 服务（开机自启、崩溃重启）。
  运行：bash deploy/scripts/deploy_manual_linux.sh
  卸载：sudo systemctl disable --now city-life-circle && rm -rf 项目目录

1.2 说明
  （1）前端无需构建：部署包已内置 frontend/dist 构建产物，后端直接托管页面，
       评委机无需安装 Node/npm；
  （2）一键脚本假设 PostgreSQL + PostGIS + pgRouting 已安装（deploy_manual
       脚本除外，它会自动安装）；
  （3）所有脚本都以"脚本自身所在目录"定位项目根目录，目录改名不影响运行。

========================================================
二、配置文件说明
========================================================

2.1 后端配置 backend/config.py
  后端所有配置均可通过"环境变量"覆盖，默认值为本地开发值，一般无需改代码。
  环境变量名与默认值如下：

  CLC_DB_HOST        localhost     数据库地址
  CLC_DB_PORT        5432          数据库端口
  CLC_DB_NAME        city_life_circle  数据库名
  CLC_DB_USER        postgres      数据库用户
  CLC_DB_PASSWORD    admin         数据库密码（部署时务必修改）
  CLC_WALK_KMH       5.0           步行速度（公里/小时）
  CLC_CYCLE_KMH      15.0          骑行速度
  CLC_DRIVE_KMH      30.0          驾车速度
  CLC_METRO_KMH      35.0          地铁速度
  CLC_BUS_KMH        20.0          公交平均速度（含停靠）

  修改示例（不修改代码）：
  Windows：set CLC_DB_PASSWORD=你的密码
  Linux：  export CLC_DB_PASSWORD=你的密码
  或写入 systemd 服务的环境文件（见 deploy_manual 脚本生成的
  /etc/city-life-circle.env）。

2.2 通用环境变量模板 deploy/config.env.example
  记录了上述数据库与速度参数的完整示例，部署时可复制为 config.env 参考。

2.3 前端配置 frontend/.env.local
  VITE_TIANDITU_KEY：天地图浏览器端 key，用于地图底图。
  不配置时前端自动回退 OSM 底图，不影响核心功能。
  修改后需重新构建前端（npm run build），或使用部署包内已构建产物。

2.4 高德 API 配置（提交版精简文件）scripts/crawlers/config.py
  仅供后端读取高德 Web 服务 key（地址搜索/逆地理编码），不含爬虫代码：
  AMAP_KEY：高德 Web 服务 key（在控制台设置 IP 白名单更安全）。
  后端解析优先级：环境变量 AMAP_KEY 优先，其次该文件。
  不配置时仅"地址搜索"降级（改用地图点选），核心分析不受影响。

2.5 Docker 部署密钥模板 deploy/docker/.env.example（仅云服务器场景需要）
  AMAP_KEY：高德 key；VITE_TIANDITU_KEY：天地图 key；NPM_REGISTRY：npm 镜像源。
  复制为 .env 填写后，由 docker compose 自动读取。

2.6 数据库配置（可选调优）
  服务器为 2 核 4G 低配环境时，建议在 postgresql.conf 中设置：
  shared_buffers = 256MB
  effective_cache_size = 1GB
  work_mem = 32MB
  maintenance_work_mem = 128MB
  max_connections = 50
  修改后执行 sudo systemctl restart postgresql 生效。

========================================================
三、密钥情况说明
========================================================

系统可选配置两把第三方 key，均已支持、且缺失时功能自动降级：

3.1 高德 Web 服务 key（后端，地址搜索/逆地理编码）
  位置：scripts/crawlers/config.py 的 AMAP_KEY，或环境变量 AMAP_KEY（优先）。
  作用：按地名定位地址、地图点选时显示地址。
  注意：若在高德控制台设置了 IP 白名单，需把运行机器的网络加入白名单，
  否则地址搜索失败（可改用地图点选，不影响核心分析）。

3.2 天地图 key（前端，地图底图）
  位置：frontend/.env.local 的 VITE_TIANDITU_KEY，构建时注入前端；
  缺失时自动回退 OSM 底图。
  注意：浏览器端 key 本身公开可见，安全靠域名白名单；若设置了域名白名单，
  需保证访问地址在白名单内，否则底图加载不出（回退 OSM）。

3.3 提交版密钥说明
  提交版（提交版本/city_life_circle）已内置两把真实 key：高德 key 在
  scripts/crawlers/config.py，天地图 key 已构建进 frontend/dist，
  开箱即用全部功能。提交版含真实密钥，请勿公开传播，评审结束建议重置。

========================================================
四、配置与运行的关系（常见问题）
========================================================

1. 数据库密码不同怎么办？
   不用改代码：设置环境变量 CLC_DB_PASSWORD 后重启后端即可。

2. 想换端口/地址？
   后端监听地址由 backend/app.py 末尾 run_production(app, host, port)
   控制，默认 0.0.0.0:5000；如需对外访问需在云服务器安全组放行该端口。

3. 想让"地址搜索"可用？
   配置 AMAP_KEY（scripts/crawlers/config.py 或环境变量），并确保高德
   控制台已为该 key 设置服务器 IP 白名单。

4. 想让底图用天地图（中文注记/影像）？
   在 frontend/.env.local 填 VITE_TIANDITU_KEY 后重新构建前端；否则自动
   回退 OSM，功能不受影响。

5. 配置文件改了需要重启吗？
   后端配置（环境变量）需重启服务生效；前端配置需重新构建；数据库调优需
   重启 PostgreSQL。

========================================================
四、安装/配置文件的完整清单
========================================================

安装脚本：
  deploy/scripts/install_windows.bat
  deploy/scripts/start_windows.bat
  deploy/scripts/install_linux.sh
  deploy/scripts/start_linux.sh
  deploy/scripts/deploy_manual_linux.sh

配置文件：
  backend/config.py                  （后端默认配置，可被环境变量覆盖）
  deploy/config.env.example          （环境变量模板）
  frontend/.env.example              （天地图 key 模板）
  scripts/crawlers/config.py         （高德 key + 数据库配置，提交版精简）
  deploy/docker/.env.example         （云服务器 Docker 密钥模板）
  frontend/vite.config.js            （开发服务器端口 5173、/api 代理到 5000）

系统运行入口：
  http://localhost:5000              （后端托管页面 + API）
  http://localhost:5173              （仅开发模式，Vite 前端）
