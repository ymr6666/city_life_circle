- 小区是**需求点**(未来人口分配起点),只转 WGS84、**不挂接路网**(避免出现在设施统计)

## 二、分级色彩重做(四边形网格 + 用户自定义图例)

- 后端 `/api/grid` 支持 **`grid_type=square`(四边形)** 与 `hex`(六边形)
- 单类设施密度按**各自达标线**(`CATEGORY_DENSITY_CAPS`):医院 0.8/km²、药店 5、小学 1.5、商场 0.5 …(此前全类别共用 8)
- 综合评分用**多维度加权标准**(维度阈值=维度内各类达标线加权和),与单类密度标准区分
- 前端:自选**中心点**(可地图选点)+ **搜索半径**(1-12km)+ **网格尺寸**(200m/500m/1km)
- 配色从蓝色改 **红→黄→绿**(低分红、高分绿,区分度明显)
- **图例区间用户可自定义**(逗号分隔输入);设施密度默认按数据自动分档并回填输入框,保证"输入框=图例=地图配色"一致
- 修复图例色块不可见(scoped 样式不作用于 innerHTML 注入元素 → 图例样式移入全局 style.css)

## 三、前端功能修复

5. **分析点位置不固定**:实测连续缩放+平移后标记像素位置 delta=0(zoomAnimation:false + 缩放隐藏已解决)
